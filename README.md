# 📱 CryptoPortfolio PWA

Aplicación Web Progresiva (PWA) de portafolio para iOS (iPhone SE) y navegadores móviles.
- 0 renovaciones, 0 certificados.
- Gráfica Donut interactiva XL.
- Cuadrícula compacta de 2 columnas con cotización en vivo.
- Conmutador EUR/USD instantáneo.
- Modo pantalla completa con `Añadir a pantalla de inicio`.
